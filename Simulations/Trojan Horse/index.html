The Lure & Delivery

📖 The Simple Story

Imagine receiving an email that looks perfectly legitimate—it appears to be from your company's finance department with an "urgent invoice" attached. The email has the right logo, the sender name looks correct, and the message creates a sense of urgency. You've seen hundreds of emails like this before, so you don't think twice about clicking the attachment.


The attacker has crafted something that looks like a gift—a free video game, an important document, or a time-sensitive request—that you naturally want to open.

⚙️ The Industry Mechanics

This is Social Engineering combined with Weaponization. The attacker creates a Dropper—a malicious executable disguised as a legitimate file.


Technical Details:

  • File extension masquerading: Invoice.pdf.exe (Windows hides known extensions by default)
  • Icon spoofing: Using PDF icons on executable files
  • Email header manipulation to appear from trusted domains
  • Embedding malicious macros in Office documents
  • Using Stager code to download additional payloads

The dropper's job is simple: execute on the victim's machine and deploy the actual Remote Access Trojan (RAT) payload.

2

Execution & Decoy Launch

📖 The Simple Story

You click on the attachment, and just as expected, a PDF invoice opens up. Everything looks normal—you see the invoice details, company logo, and payment information. You're satisfied this was legitimate.


But here's what you didn't see: while the PDF was opening, a thief silently slipped out of the box and quietly hid in your closet. You got exactly what you expected (the invoice), but something else came along for the ride.

⚙️ The Industry Mechanics

This is the Execution Phase. The dropper performs two simultaneous actions:


Technical Process:

  1. Decoy Launch: Opens the legitimate PDF to maintain user trust and avoid suspicion
  2. Payload Extraction: Unpacks the embedded RAT from its encrypted container
  3. Memory Loading: Loads malicious code into memory without writing to disk
  4. Process Creation: Spawns the RAT in a hidden or suspended state

The decoy document is critical—it prevents the user from realizing anything malicious occurred and buys time for the malware to establish itself.

3

Persistence (Digging In)

📖 The Simple Story

Now that the thief is inside your house, they don't want to lose their position. So they make copies of your house keys and rewire your electrical system. Now, every time you turn on the lights in the morning, the thief gets woken up automatically.


Even if you reboot your computer (turn off the lights and turn them back on), the malware will start right back up—because it's configured to launch automatically every time the system starts.

⚙️ The Industry Mechanics

This is Persistence—ensuring the malware survives system reboots and maintains long-term access.


Common Persistence Mechanisms:

  • Registry Run Keys: HKCU\Software\Microsoft\Windows\CurrentVersion\Run
  • Registry RunOnce Keys: Execute once on next boot
  • Scheduled Tasks: Create tasks that run at logon or system startup
  • Startup Folder: Place shortcuts in user's startup directory
  • Service Creation: Register as a Windows service
  • WMI Event Subscriptions: Execute on system events

Advanced malware uses multiple persistence methods simultaneously for redundancy.

4

Defense Evasion & Process Injection

📖 The Simple Story

The thief knows your house has security cameras, so they put on a security guard's uniform. Now when the cameras scan the house, they see what looks like a legitimate security guard going about normal duties.


The malware does the same thing—it hides inside processes that your antivirus already trusts, so security software sees only "normal" system activity.

⚙️ The Industry Mechanics

This is Defense Evasion through Process Injection, specifically Process Hollowing.


Process Hollowing Technique:

  1. Create a legitimate process (e.g., svchost.exe, explorer.exe) in suspended state
  2. Unmap the legitimate code from the process's memory
  3. Write malicious code into the empty memory space
  4. Update the process's entry point to point to malicious code
  5. Resume the process—now running malware but appearing legitimate

Other Evasion Techniques:

  • DLL Injection: Load malicious DLL into trusted process
  • API Hooking: Intercept security software calls
  • Timestomping: Modify file timestamps to appear legitimate
  • Obfuscation: Encrypt or encode malicious code
5

Command & Control (The Beacon)

📖 The Simple Story

Now the thief uses a hidden radio to call their boss and say "I'm in." The security guards at the gate only check people entering the building—they don't inspect people leaving. So the thief's radio call goes out disguised as normal building traffic.


The malware establishes a connection back to the attacker's server, asking for instructions on what to do next.

⚙️ The Industry Mechanics

This is Command & Control (C2) establishment through Beaconing.


C2 Communication:

  • Outbound Connections: Firewall rules typically allow outbound traffic, so malware initiates connections from the victim machine
  • Protocol Tunneling: C2 traffic disguised as HTTPS, DNS, or ICMP
  • Domain Generation Algorithms (DGA): Generate random domains to avoid blacklists
  • Fast Flux DNS: Rapidly change IP addresses for C2 domains
  • Sleep/Beacon Intervals: Periodic check-ins to avoid detection

Common C2 Frameworks: Cobalt Strike, Metasploit, Empire, Covenant

6

Action on Objectives & Mitigation

📖 The Simple Story

The boss now tells the thief what to steal: credit card numbers from your wallet, passwords from your computer, or sensitive documents from your filing cabinet. The thief gathers everything and sends it back through the hidden radio.


To catch this thief, you need smart security that watches how people behave, not just what uniform they're wearing. If someone is copying all your files at 3 AM, that's suspicious behavior regardless of their outfit.

⚙️ The Industry Mechanics

This is Actions on Objectives—the attacker's end goals.


Common RAT Capabilities:

  • Keylogger: Capture all keystrokes (passwords, messages)
  • Screen Capture: Take screenshots at intervals
  • File Exfiltration: Steal documents, databases, credentials
  • Webcam Access: Activate camera remotely
  • Lateral Movement: Spread to other machines on network
  • Privilege Escalation: Gain admin/root access

Modern Defense: EDR (Endpoint Detection and Response)

Unlike traditional signature-based antivirus, EDR monitors behavioral patterns, detects anomalies, and can automatically respond to threats in real-time.

🛡️ Defensive Takeaways: This simulation demonstrates why modern security requires layered defenses—email filtering, user awareness training, EDR solutions, network monitoring, and regular security audits.

📧 Email Security

Implement SPF, DKIM, DMARC. Use advanced threat protection for attachments and URLs.

👥 User Training

Regular phishing simulations and security awareness training to recognize social engineering.

🔍 EDR Solutions

Deploy behavioral analysis tools that detect suspicious process activity and lateral movement.

🌐 Network Segmentation

Limit lateral movement with proper network segmentation and zero-trust architecture.
